# my-fucking-hyprland-configuration

## Hyprland

[Hyprland](https://wiki.archlinux.org/title/Hyprland) es un compositor Wayland dinámico. Se puede arrancar desde TTY o desde un gestor de pantalla como SDDM.

```bash
# Instalar Hyprland
sudo pacman --sync hyprland
```

| Paquete | Propósito |
|---------|-----------|
| `hyprland` | Compositor Wayland dinámico y personalizable |
